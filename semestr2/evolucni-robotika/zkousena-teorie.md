# Zkoušená teorie

## Základy evoluce

- charakteristiky fitness funkce + které jsou vhodné pro evoluční vývoj
- jednoduchý genetický algoritmus, věta o schématech
- bootstrap problém a jak se řeší
- porovnejte genetické algoritmy, genetické programování, gramatickou evoluci
- jak se kódují jedinci

## Pokročilá evoluce

- co je koevoluce + jak se sleduje, zda dochází ke zlepšování jedinců při koevoluci
- přímé kódování, nepřímé kódování + 3 příklady nepřímého kódování
- algoritmus NEAT
- zavádějící úlohy a jak se řeší
- novelty search

## Robotika

- jaké architektury/typy neuronových sítí se používají při evoluci řízení pro roboty
- reaktivní řízení + příklad úlohy, kde lze využít
- senzorově-motorická koordinace a příklad
- minimální simulace
- robotický roj, feromonová robotika + algoritmus pro prohledávání grafu (vrcholu) v polynomiálním čase

- učení vs. evoluce
- učení neuronových sítí s učitelem vs. evoluční učení neuronových sítí – výhody, nevýhody, metody
